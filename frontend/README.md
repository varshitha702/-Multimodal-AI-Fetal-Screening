# frontend/: Next.js web client

Owner: **Rakshitha V** (frontend).

Next.js 15 (App Router) + TypeScript + Tailwind CSS + shadcn/ui components (`src/components/ui`),
talking to the FastAPI backend.

## Run

```powershell
# terminal 1, from the repository root: start the backend on :8000
scripts\run_backend.bat

# terminal 2
cd frontend
npm install
npm run dev            # http://localhost:3000
```

The API URL defaults to `http://localhost:8000`; override it with `NEXT_PUBLIC_API_URL` (see `.env.example`).

## Features

* Drag-and-drop upload (PNG/JPEG, 10 MB), with client-side checks that mirror the API.
* Pixel spacing input. For HC18 images it is **auto-filled**: the file's SHA-256 is looked up in
  `src/lib/hc18-pixel-sizes.json`, generated by `python scripts/export_pixel_sizes.py`. Hashes are used
  because the official HC18 test set reuses the training-set filenames.
* Results: original / overlay with fitted ellipse / mask side by side; metric cards (HC, ellipse
  diameters, area, confidence); quality warnings; measurement details.
* Print report (browser print → *Save as PDF*), JSON and overlay-PNG downloads.
* Loading, empty and error states; API status indicator; responsive; light/dark theme.
* `/model` page with the held-out test metrics served by `/api/v1/model-info`.
* "Not a medical device" disclaimer on every page and in the report.

```text
src/lib/api.ts           typed API client
src/lib/pixel-size.ts    HC18 pixel-spacing auto-fill
```
